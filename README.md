# تطبيق شات (نص + صور + فيديو)

## التشغيل

```bash
npm install
npm start
```

بعدها افتح: http://localhost:3000

لو عايز تجرب من موبايل على نفس الواي فاي، افتح `http://<IP-الكمبيوتر>:3000`.

## هيكل الملفات

```
chat-app/
├── package.json
├── server.js          # Express + Socket.IO + رفع الملفات (multer)
└── public/
    └── index.html     # الواجهة (عربي RTL)
```

عند التشغيل بيتعمل تلقائيًا: فولدر `uploads/` (الصور والفيديوهات) وملف `history.json` (آخر 500 رسالة).

## المميزات

- رسائل نصية فورية (Socket.IO) مع مؤشر "بيكتب..." وقائمة المتصلين
- إرسال صور (jpg/png/gif/webp) وفيديو (mp4/webm/mov) مع تعليق اختياري وشريط تقدم الرفع
- لصق صورة من الحافظة (Ctrl+V)
- حفظ سجل الرسائل بعد إعادة تشغيل السيرفر
- الحد الأقصى للملف 50 ميجا (غيّره من `MAX_FILE_MB` في server.js)

## ملاحظات قبل النشر الفعلي

الكود ده نسخة أساسية لشات عام واحد. قبل ما تنشره للناس محتاج تضيف: تسجيل دخول حقيقي (حسابات وكلمات سر)، غرف أو محادثات خاصة، وتخزين الملفات على خدمة سحابية بدل القرص المحلي.
